# Design notes

Drop reference images in this folder and record the decisions here.

## Current direction (placeholder)
The theme in `src/theme.ts` uses a calm indigo brand (`#5B5BD6`) on a soft
off-white background, with generous spacing and rounded cards. This is a
starting point to be replaced once reference images are added.

## Open questions
- Brand colour and logo.
- Typography (system font vs. a custom Arabic/Latin pair).
- Card artwork / gradients.
- Vendor and admin density (compact tables vs. cards).

## Rules
- Match the mood, colours, and layout of the references.
- Where references conflict, ask before choosing.
- Never copy other apps' logos, icons, or exact designs.
